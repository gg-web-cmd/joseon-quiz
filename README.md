# 📜 초등 5학년 사회 퀴즈 - 도전! 조선 문화 퀴즈 탐험대

초등학교 5학년 사회과 교육과정(조선 시대의 발전과 민족 문화)을 바탕으로 제작된 반응형 퀴즈 웹 애플리케이션입니다.  
교실 대형 TV 화면, 전자칠판, 태블릿, 학생 개인 스마트폰 등 다양한 기기에서 시원시원한 가독성을 제공합니다.

---

## 🎯 주요 기능
- **10개의 핵심 문항**: 훈민정음, 측우기, 앙부일구, 자격루, 풍속화, 김홍도, 신사임당, 조선백자, 조선왕조실록, 수원 화성
- **즉각적인 정/오답 피드백**: 선택 즉시 O/X 표시 및 내장 Web Audio 효과음 재생
- **쉬운 해설 제공**: 초등학생 눈높이에 맞춘 1~2문장의 친절한 설명
- **결과 및 성취도**: 총점(100점 만점) 및 점수별 격려 칭찬 메시지, '다시 풀기' 지원
- **반응형 대형 UI**: 고대비 색상과 큼직한 폰트, 누르기 편한 터치 버튼

---

## 🚀 실행 방법
별도의 프로그램 설치 없이 `index.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 실행할 수 있습니다.
